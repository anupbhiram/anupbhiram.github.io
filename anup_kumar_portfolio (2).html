Subscription Features

  • Auto-renew — ISP level + operator subscriber-level override
  • Advance renewal — queue next pack before expiry
  • Future activation — set future start date
  • Upgrade — higher duration / higher price pack
  • Renew intent — subscriber-initiated signal from FE
  • Multiple plans — dual slot (plan 1 + plan 2 simultaneously)
  • Switch plan — immediate replacement with refund logic
  • Pause / Resume — temp suspension, original terms on resume

Onboarding Flow

  • Sales captures ISP details and unique plan requirements
  • CFO + CRO approval gate before onboarding proceeds
  • ISP created on CMS first; plans mapped under ISP account
  • Ops syncs ISP to Bundlr, creates username, sends first password via email
  • Ops creates first operator account; credentials sent to ISP email
  • ISP recharges wallet, sets operator prices, assigns packs
  • Operator sets subscriber prices, onboards users, assigns packs
  • Activation: operator virtual wallet → ISP real wallet (OTTplay revenue)

Distributor Channel

  • Electronics distributors + retailers sell via coupon codes
  • Same onboarding as ISP — CMS first, then Bundlr sync
  • Distributor recharges wallet to generate coupon codes
  • Codes assigned to retailers → retailers share with subscribers
  • Commission on both activation AND renewal events
"B2B2C means designing for three user types simultaneously — ISP, operator, end user — each with different mental models. You can't optimise for one at the expense of the others."

Three-Track Search Strategy

  • Track 1 — Exact and Phrase: titles, sports teams, synonyms. Sorted by recency + relevance.
  • Track 2 — Prefix and Near-Phrase: short queries use prefix autocomplete; long queries allow slight word variation. Sorted by rating × recency.
  • Track 3 — Fuzzy: misspelling and phonetic fallback. "bhaubali" → "Baahubali". Safety net for zero-results.
  • All 3 tracks in a single Elasticsearch _msearch — one network round trip.

Pipeline and Architecture

  • Client → Node API (/universal_autocomplete/) → Python service → Elasticsearch
  • NLP intent parsing — entity + attribute extraction before search
  • Fuzzy + phonetic matching for Indian transliterations
  • Automated synonym libraries — S2 = Season 2 = Part 2
  • 14 context parameters — premium, parental, maturity, provider filters
  • Sports widgets + tournament cards (conditional, appear above results)
  • Merge, de-duplicate, rank — final ordered response
"Search is not a feature — it's a signal. Every zero-result is a user telling you what they want that you're not giving them."
